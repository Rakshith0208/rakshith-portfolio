## Content Creation
A dedicated `content.html`-style section is integrated into the main portfolio as **CONTENT**.
Each work opens a separate video page:
- `video-01.html`
- `video-02.html`
- `video-03.html`
- `video-04.html`

To add videos, put MP4 files in `videos/` using:
- `video-01.mp4`
- `video-02.mp4`
- `video-03.mp4`
- `video-04.mp4`

Then the corresponding work page will play that video.
